# 💳 SafiLedger

The business payments brain for businesses & banks. Built with SwiftUI and Firebase for Cohort 2 of the AUCA SwiftUI Program.

## What it does
- Secure user authentication (Sign in / Sign up)
- Real-time cloud database syncing with Firebase Firestore
- Each user sees *only* their own private transaction data
- Automatic fraud flagging logic built into the data model
- Clean MVVM architecture separating logic from the UI

## How to run
1. Clone this repository: `git clone https://github.com/mucyobilly10/safiledger.git`
2. Open `SafiLedger.xcodeproj` in Xcode
3. Add your own `GoogleService-Info.plist` from your Firebase project to the app target
4. Press Run (Cmd + R)
